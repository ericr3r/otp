================================================================================
                          Key Format Specifications
================================================================================

OpenSSH Public Key File Format:
+------------------+--------------------+---------------+
| Key Type String  | Base64 Encoded Key | Comment       |
+------------------+--------------------+---------------+
       |                    |                  |
       |                    |                  └─ Optional: "user@host"
       |                    |
       |                    └─ Wire format encoding of:
       |                       - Key type (again)
       |                       - Curve/algorithm params
       |                       - Public key material
       |                       - Application string
       |                       - [Optional: flags]
       |                       - [Optional: key_handle]
       |
       └─ "sk-ecdsa-sha2-nistp256@openssh.com" or
          "sk-ssh-ed25519@openssh.com"

ECDSA-SK Wire Format (inside base64):
┌─────────────────────────────────────────────────────────────┐
│ string: "sk-ecdsa-sha2-nistp256@openssh.com"                │
│ string: "nistp256"                                          │
│ string: EC point (65 bytes: 0x04 || X || Y)                │
│ string: "ssh:"                         ◄─ Application      │
│ [uint32: flags]                        ◄─ Optional (8.3+)  │
│ [string: key_handle]                   ◄─ Optional (8.3+)  │
└─────────────────────────────────────────────────────────────┘

Ed25519-SK Wire Format (inside base64):
┌─────────────────────────────────────────────────────────────┐
│ string: "sk-ssh-ed25519@openssh.com"                        │
│ string: Public key (32 bytes)                               │
│ string: "ssh:"                         ◄─ Application      │
│ [uint32: flags]                        ◄─ Optional (8.3+)  │
│ [string: key_handle]                   ◄─ Optional (8.3+)  │
└─────────────────────────────────────────────────────────────┘
